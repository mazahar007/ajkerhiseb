# হিসেবের খাতা — আয়-ব্যয়ের হিসাব

বাংলা, লাইট ভার্সন, এক পাতার স্ট্যাটিক অ্যাপ। কোনো ব্যাকএন্ড নেই — ডেটা ব্রাউজারের localStorage-এ থাকে।

## যা আছে
- হাতে থাকা টাকা (বড় অংকে), মোট আয়, মোট ব্যয়, ব্যাংক উত্তোলন, বাকি (আয় − ব্যয়) — সব নিজে থেকে হিসাব হয়
- এন্ট্রি যোগ / বদলানো / মোছা: ধরন আয় / ব্যয় / ব্যাংক উত্তোলন, আইটেম, টাকা, তারিখ, নোট
- ধরন অনুযায়ী ছাঁকনি, আইটেম খোঁজা, মাস অনুযায়ী হিসাব
- প্রথমবার খুললে ২৪ নভেম্বর ২০২৬-এর আসল হিসাব লোড হয়

## আসল হিসাব (২৪ নভেম্বর ২০২৬)
- ২২টি ব্যয়, মোট ব্যয় ৩,২০০ টাকা
- ব্যাংক থেকে উত্তোলন ৫,০০০ + ৪,০০০ = ৯,০০০ টাকা
- মোট আয় ০, বাকি (আয় − ব্যয়) −৩,২০০, হাতে থাকা টাকা ৫,৮০০
