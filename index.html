📋 বাজেট লিস্ট —

আলাদা বাজেটের তালিকা। প্রতিটা আইটেমের বাজেট থেকে ওই মাসের খরচ নিজে থেকেই মাইনাস হয়ে বাকি দেখাবে। খরচ ধরা হয় ওই মাসে ওই নামের আইটেমের মোট ব্যয় দিয়ে; নাম না মিললে ওই ক্যাটাগরির মোট ব্যয় দিয়ে। প্রতিটা আইটেমের নিজের তারিখ থাকে। ক্যাটাগরি তালিকা থেকে বেছে নেওয়া যায়, আবার নিজে লিখে নতুন ক্যাটাগরিও দেওয়া যায় — নতুন ক্যাটাগরি মনে রাখা হয়, পরের বার তালিকায় দেখাবে। “খরচে যোগ করুন” চাপলেই আইটেমটি আজকের তারিখে, বাজেটের অংকে, খরচের তালিকায় যোগ হয়ে যাবে।

📥 ব্যাকআপ

মোট এন্ট্রি: ০টি। ব্যাকআপ নিলে এই অ্যাকাউন্টের পুরো হিসাব ফাইলে নেমে যাবে — ফোন বদলালেও আবার আপলোড করে ফিরিয়ে আনা যাবে।

সাবধান: এটা এই অ্যাকাউন্টের সব এন্ট্রি মুছে দেবে (Supabase চালু থাকলে সেখান থেকেও)। আগে ব্যাকআপ নিয়ে নিন। অন্য অ্যাকাউন্টের হিসাব মুছবে না।

⚙️ সিঙ্ক সেটিংস — Supabase

অবস্থা: ● লোকাল মোড

লোকাল মোডে ডেটা শুধু এই ব্রাউজারেই থাকে। Supabase যুক্ত করলে সব ডিভাইসে একই হিসাব সিঙ্ক হবে। চাবি দুটো শুধু এই ব্রাউজারে থাকে, কোথাও পাঠানো হয় না। লোকাল অ্যাকাউন্টগুলো এই ব্রাউজারেই থাকে — অন্য ডিভাইসে আবার অ্যাকাউন্ট খুলতে হবে, যতক্ষণ না Supabase সিঙ্ক চালু হয়।

Supabase প্রজেক্ট বানাতে (ফ্রি):

  1. supabase.com → New Project (ফ্রি প্ল্যান) → নাম দিন ajkerhiseb
  2. SQL Editor → New Query → এই repo-র supabase/schema.sql ফাইলের পুরোটা পেস্ট → Run
  3. Project Settings → API থেকে Project URL আর anon public key কপি করুন
  4. উপরে বসিয়ে “সংরক্ষণ ও সিঙ্ক চালু করুন” চাপুন — প্রথম সিঙ্কে এই ব্রাউজারের হিসাবটাই Supabase-এ উঠে যাবে

🚪 লগআউট

প্রতিটা অ্যাকাউন্টের ডেটা আলাদাভাবে এই ব্রাউজারে থাকে (localStorage) — পিন দিয়ে সুরক্ষিত। Supabase যুক্ত করলে সব ডিভাইসে সিঙ্ক হবে।
